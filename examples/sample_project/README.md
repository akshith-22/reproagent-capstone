# Tiny Sentiment Demo

This example labels a line of text as positive or negative.

## Dependencies

Dependencies are listed in `requirements.txt`.

## Run

```bash
python3 main.py --input data/input.txt --output results/prediction.txt
```

The input is `data/input.txt`. The output is written to
`results/prediction.txt`.

## Test case

For the input `I love this class`, the expected result is a `positive` label.
